Data Handling

Live telemetry is accepted only from the configured BLE characteristic.

Ride logging requires a connected receiver and recent telemetry.

Power is treated as a derived value when it is calculated as voltage × battery current.

Vehicle speed is displayed from the Receiver's validated speed_kmh field. RPM is not silently converted into km/h.
